# ColumbinaMath

Plataforma web gamificada de matemática básica para crianças e adolescentes, 
desenvolvida como projeto de Extensão I / Engenharia de Software (IFMT).

## Visão do Produto
Tornar o aprendizado de matemática básica acessível, visualmente atrativo e 
motivador, transformando reforço escolar em uma experiência que o aluno 
escolhe fazer — não que é obrigado a fazer.

## Stack
- Back-end: Python + Django
- Front-end: Django Templates + Tailwind CSS
- Banco de dados: SQLite (dev) / PostgreSQL (produção)
